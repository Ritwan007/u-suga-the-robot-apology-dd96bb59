## Entry (184 chars)

> I'm sorry I fed the dog twice this morning because I forgot I had already fed him at seven.
> I have learned my memory needs a marker, so now I flip the tag on his bowl after every meal.

## Run

```sh
node main.ts
```

Writes the entry to `/output/entry.txt` (UTF-8, 184 chars, exactly two lines, no trailing newline). The program self-checks the gate (1–400 chars, two lines, valid UTF-8) before writing.
